硬性條件：蛋白質殘留必須為 0 μL。先找酸、鹼皆為 0 的精準解；若沒有，顯示酸鹼總殘留最低的合格方案。

計算模型說明

本試用版採用簡化數學模型：每次加入試劑時，先中和相反試劑殘留，再由剩餘有效量消耗蛋白質；蛋白質為 0 後不再被消耗，剩餘試劑列為殘留。這是依目前討論規則建立的模型，尚不代表已驗證實際化學反應，請先用已知數據核對。
